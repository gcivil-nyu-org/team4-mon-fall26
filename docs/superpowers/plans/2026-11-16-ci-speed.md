# CI speed (#267) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut each Travis job from about 38 minutes to about 10 minutes with a test-only fast hasher, parallel tests with combined coverage, and no duplicate push builds.

**Architecture:** `settings.py` picks `MD5PasswordHasher` only when `sys.argv[1]` is `test`. Both Travis jobs run `manage.py test --parallel auto`; coverage runs in parallel mode from `setup.cfg` and is combined before the report. A build-level Travis `if:` keeps push builds for `testing` and `main` only.

**Tech Stack:** Django 6.1, Python 3.12 (Travis) / 3.14 (local venv), coverage 7.x, tblib, Travis CI (jammy), Postgres 17 in Docker.

**Spec:** `docs/superpowers/specs/2026-11-16-ci-speed-design.md`

## Global Constraints

- Branch: `git fetch origin && git checkout -b nihal/ci-speed origin/testing`.
- One commit per task, message prefixed `#267:`. No Claude co-author line or footer in commits or the PR.
- Do not change product code. Only `playnyu/settings.py` (hasher block), `playnyu/tests.py`, `setup.cfg`, `requirements-dev.txt`, `.gitignore`, `.travis.yml`, `AGENTS.md`, `docs/WORKFLOW.md`, `docs/DATABASE.md`, `README.md`.
- Production, `runserver`, gunicorn and management commands keep Django's default `PASSWORD_HASHERS`. `AUTH_PASSWORD_VALIDATORS` does not change.
- Keep `coverage report --fail-under=80`, and keep `[coverage:run]` `source = .` and the current `omit` list unchanged.
- Deploy blocks in `.travis.yml` do not change.
- Write `AGENTS.md` edits in the style of `~/.claude/CLAUDE.md`: imperative, 20 words or fewer per instruction, keep commands exact.
- Format with `black .` (version from `requirements-dev.txt`).

## Review Focus

1. A command whose first argument is not `test` (`runserver`, `migrate`, gunicorn's `playnyu.wsgi`) must keep PBKDF2. Pinned by Task 1's subprocess test.
2. Spawned workers on macOS must also get MD5 (they rebuild settings from a copied `sys.argv`). Pinned by Task 1's in-process test, run under `--parallel auto` in Task 2.
3. `coverage report` after a parallel run with no `combine` reports "No data to report." Every documented command list must include `coverage combine`. Checked in Task 2 Step 6.
4. A crashed local parallel run leaves `default_<n>.sqlite3` and `.coverage.*` files; `git status` must stay clean. Checked in Task 2 Step 6.
5. The Postgres job must still run `RoleLockTests` and `RoleRaceTests` in parallel (skipped count stays 1). Checked in Task 2 Step 5 and Task 4.

### Task 1: Fast password hasher in tests only

**Files:**
- Modify: `playnyu/settings.py` (add `import sys`; add a block after `AUTH_PASSWORD_VALIDATORS`)
- Test: `playnyu/tests.py` (new class `TestHasherTests`)

**Interfaces:**
- Produces: `settings.TESTING: bool`, true only when `sys.argv[1:2] == ["test"]`.

- [ ] **Step 1: Write the failing tests** in `playnyu/tests.py`

```python
import os
import subprocess
import sys

from django.conf import settings
from django.contrib.auth.hashers import get_hasher

MD5 = "django.contrib.auth.hashers.MD5PasswordHasher"
PBKDF2 = "django.contrib.auth.hashers.PBKDF2PasswordHasher"
SCRIPT = (
    "import sys; sys.argv = sys.argv[1:]\n"
    "from django.conf import settings\n"
    "print(settings.PASSWORD_HASHERS[0], settings.TESTING)\n"
)


class TestHasherTests(SimpleTestCase):
    def test_test_run_uses_md5(self):
        self.assertTrue(settings.TESTING)
        self.assertEqual(settings.PASSWORD_HASHERS, [MD5])
        self.assertEqual(get_hasher().algorithm, "md5")

    def first_hasher(self, *argv):
        env = {**os.environ, "DJANGO_SETTINGS_MODULE": "playnyu.settings"}
        result = subprocess.run(
            [sys.executable, "-c", SCRIPT, *argv],
            cwd=settings.BASE_DIR, env=env, capture_output=True, text=True, check=True,
        )
        return result.stdout.split()

    def test_other_commands_keep_the_default_hasher(self):
        for argv in (["manage.py", "runserver"], ["manage.py", "migrate"],
                     ["gunicorn", "playnyu.wsgi"], ["manage.py", "shell", "test"]):
            with self.subTest(argv=argv):
                self.assertEqual(self.first_hasher(*argv), [PBKDF2, "False"])

    def test_manage_py_test_sets_the_flag(self):
        self.assertEqual(self.first_hasher("manage.py", "test"), [MD5, "True"])
```

- [ ] **Step 2: Run the tests and make sure they fail**

Run: `python manage.py test playnyu.tests.TestHasherTests`
Expected: FAIL / ERROR with `AttributeError: 'Settings' object has no attribute 'TESTING'`.

- [ ] **Step 3: Add the hasher block to `playnyu/settings.py`**

After `AUTH_PASSWORD_VALIDATORS`, set `TESTING = sys.argv[1:2] == ["test"]`, and when true set `PASSWORD_HASHERS = ["django.contrib.auth.hashers.MD5PasswordHasher"]`. Comment, two lines: MD5 is fast and weak; only `manage.py test` uses it, so production keeps Django's default hashers.

- [ ] **Step 4: Run the tests and make sure they pass**

Run: `python manage.py test playnyu.tests.TestHasherTests`
Expected: `Ran 3 tests`, `OK`.

- [ ] **Step 5: Run the full suite serial and record the time**

Run: `time python manage.py test 2>&1 | tail -5`
Expected: `OK (skipped=2)`. Wall time well under Task 0 Step 2.

- [ ] **Step 6: Lint and commit**

```bash
black . && flake8 .
git add playnyu/settings.py playnyu/tests.py
git commit -m "#267: use a fast password hasher in tests only"
```
